# ex09 viva — Run a container from Docker Hub

1. **What is Docker Hub?** A public registry for storing and distributing container images.
2. **What does `docker pull` do?** Downloads an image (and its layers) from a registry to the local machine.
3. **What does `docker run -d` do?** Starts a container in detached (background) mode.
4. **How do you see running containers?** `docker ps` (add `-a` to include stopped ones).
5. **Why might you prefer a Hub image over building your own?** It's pre-built, versioned and maintained — saves writing a Dockerfile for common software.
