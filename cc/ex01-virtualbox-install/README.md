# ex01 - Install VirtualBox / VMware

No program — GUI install only.

## Aim
Install VirtualBox/VMware Workstation with a Linux or Windows flavour on top of the host OS.

## Steps
1. Download VirtualBox for the host OS from virtualbox.org.
2. Run the installer with defaults.
3. Create a new VM, attach a Linux/Windows ISO, and complete the guest install.

## Result
A guest OS runs inside VirtualBox on the host machine.
