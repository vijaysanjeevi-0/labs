# ex01 viva — VirtualBox install

1. **What is a hypervisor?** Software that creates and manages virtual machines on physical hardware.
2. **What is a guest OS vs host OS?** The host OS runs on the real hardware; the guest OS runs inside the VM, managed by the hypervisor.
3. **What are VirtualBox Guest Additions for?** Better display resolution, shared clipboard/folders and smoother mouse integration inside the guest.
4. **What resources does a VM need from the host?** CPU cores, RAM, disk space and (for networking) a virtual network adapter.
5. **Bridged vs NAT networking in VirtualBox?** Bridged gives the VM its own IP on the physical LAN; NAT shares the host's IP and hides the VM behind it.
