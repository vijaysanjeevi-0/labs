# ex03 - Google App Engine hello world

## Aim
Create a hello-world app engine app using Python.

## Files
- `app.yaml` — app config (points to `index.py`)
- `index.py` — the handler

## Run
```
dev_appserver.py app.yaml
```
Open `http://localhost:8080/`.

## Output
```
Content-Type: text/plain

Hello there Chuck
```
