# General viva questions — Cloud Computing

Exercise-specific questions are in the `VIVA.md` inside each exercise folder.

1. **What is cloud computing?** On-demand delivery of compute, storage and services over the internet, billed by usage instead of owned hardware.
2. **IaaS vs PaaS vs SaaS?** IaaS gives raw VMs/storage/network; PaaS gives a managed runtime to deploy apps on (e.g. App Engine); SaaS gives a finished application (e.g. Gmail).
3. **What is virtualization?** Running multiple isolated "guest" OSes on one physical "host" machine via a hypervisor.
4. **Type 1 vs Type 2 hypervisor?** Type 1 runs directly on hardware (ESXi, Xen); Type 2 runs as an application on a host OS (VirtualBox, VMware Workstation).
5. **What is a container, and how does it differ from a VM?** A container packages an app with its dependencies and shares the host kernel (lightweight); a VM virtualizes an entire OS (heavier, fully isolated).
6. **What is CloudSim used for?** Simulating cloud data centres, VMs and scheduling policies without needing real cloud infrastructure.
7. **What is Hadoop / MapReduce?** A framework for distributed storage (HDFS) and parallel processing (map then reduce) of large datasets across a cluster.
8. **Public vs private vs hybrid cloud?** Public is shared infrastructure open to any customer; private is dedicated to one organisation; hybrid combines both.
