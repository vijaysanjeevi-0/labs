# Ex 7.1 — Introduction to the Raspberry Pi platform

**Aim:** Study the Raspberry Pi Pico platform.

**Apparatus / Tools required:** None (study experiment).

The Raspberry Pi Pico uses the RP2040 microcontroller (dual-core Arm Cortex-M0+) with GPIO, ADC, I2C, SPI and UART, programmed in MicroPython via the Thonny IDE. The Pico W adds Wi-Fi.

**Program:** No program — study only.

**Result:** The Raspberry Pi Pico platform and its interfaces were studied.
