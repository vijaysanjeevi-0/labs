# Ex 7.1 viva — Raspberry Pi Pico platform

1. **What chip powers the Pico?** RP2040 — dual-core Arm Cortex-M0+.
2. **Pico vs Pico W?** The W adds a Wi-Fi/Bluetooth radio; the base Pico has none.
3. **What interfaces does the Pico expose?** GPIO, ADC, I2C, SPI, UART, PWM.
4. **What IDE/tool is used to program it in MicroPython?** Thonny.
5. **Pico vs a full Raspberry Pi (3/4/5)?** The Pico is a microcontroller board (no OS, runs one program); the full Raspberry Pi is a single-board computer running Linux.
