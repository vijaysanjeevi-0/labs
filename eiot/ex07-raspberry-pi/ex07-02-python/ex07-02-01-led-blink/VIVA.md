# Ex 7.2.1 viva — LED blink

1. **What is MicroPython?** A lean Python 3 implementation for microcontrollers.
2. **`Pin.OUT` vs `Pin.IN`?** Output drives the pin; input reads its level.
3. **`sleep` vs `sleep_ms`?** `sleep` takes seconds; `sleep_ms` takes milliseconds.
4. **What chip is on the Pico?** RP2040, dual-core Arm Cortex-M0+.
5. **How do you stop a running MicroPython script in Thonny?** Press the Stop/Restart button, which sends a keyboard interrupt to the board.
