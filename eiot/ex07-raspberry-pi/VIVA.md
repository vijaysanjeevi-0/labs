# Viva: ex07-raspberry-pi

**Q1. What is MicroPython?**
A lean Python 3 implementation for microcontrollers.

**Q2. What chip is on the Pico?**
RP2040, dual-core Arm Cortex-M0+.

**Q3. Pin.OUT vs Pin.IN?**
Output drives the pin; input reads its level.

**Q4. sleep vs sleep_ms?**
sleep takes seconds, sleep_ms takes milliseconds.

**Q5. Why use a pull-down with a switch?**
To keep the input at a defined LOW when the switch is open.
