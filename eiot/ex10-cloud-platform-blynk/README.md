# Ex 10 — Cloud platform setup (Blynk)

**Aim:** Set up a cloud platform (Blynk) to log data.

**Apparatus / Tools required:** A Blynk account, a web browser.

**Algorithm / Procedure**
1. Sign up / log in at blynk.cloud.
2. Create a new template, add datastreams: V0 (LED, digital), V3 and V4 (temperature C/F, double).
3. Create a device from the template; copy its Auth Token.
4. Add a dashboard: a switch widget on V0, gauges on V3/V4.
5. Keep the Auth Token for ex11 and ex12.

**Program:** No program — cloud dashboard setup only.

**Sample Output:** device and dashboard visible in the Blynk console, with widgets bound to V0, V3, V4.

**Result:** A Blynk cloud platform and dashboard were set up successfully for logging data.
