# Viva: ex10-cloud-platform-blynk

**Q1. What is Blynk?**
An IoT cloud platform with a dashboard and mobile app.

**Q2. What is a virtual pin?**
A software channel for exchanging data, not tied to a physical pin.

**Q3. What is the Auth Token?**
A unique key that identifies the device to the cloud.

**Q4. What protocol does it use?**
Blynk's own protocol over TCP/MQTT.

**Q5. What is a datastream?**
A typed channel (int, double, string) bound to a virtual pin.
