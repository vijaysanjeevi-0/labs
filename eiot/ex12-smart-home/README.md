# ex12-smart-home

## Aim
Design an IoT-based smart home automation system.

## Tools
Pico W, LED on GP16, Wi-Fi, Blynk.

## Procedure
Set credentials and token in `smart_home.py`, run it, then toggle a switch widget on virtual pin V0.

## Expected output
LED turns on and off from the Blynk dashboard.

## Notes
The record wrote the handler as `@blynk.on("VO")` (letter O); the virtual pin is `V0`.
