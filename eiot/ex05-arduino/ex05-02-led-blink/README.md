# Ex 5.2 — Arduino programming: LED blink

**Aim:** Write and run a first Arduino sketch.

**Tools:** Arduino IDE 2.0, Arduino UNO, USB cable.

**Run:** open `ex05-02-led-blink/ex05-02-led-blink.ino`, select board + port, Upload.

**Expected output:** the on-board LED (pin 13) blinks, 1 s on / 1 s off.
