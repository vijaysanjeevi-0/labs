# Ex 5.1 — Introduction to the Arduino platform

**Aim:** Study the Arduino platform.

**Apparatus / Tools required:** None (study experiment).

Arduino is an open-source board and IDE. The UNO has an ATmega328P with 14 digital I/O pins (6 PWM-capable), 6 analog inputs, a USB interface and a 16 MHz clock. Sketches are written in C/C++ and uploaded over USB via the bootloader.

**Program:** No program — study only.

**Result:** The Arduino platform and the UNO board's features were studied.
