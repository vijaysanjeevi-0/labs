# Ex 2.2 — Block transfer

**Aim:** Copy a block of bytes from one memory area to another using indirect addressing.

**Tools:** Keil uVision (simulator), AT89C51.

**Run:** preload 30H–35H in the memory window, build `block_transfer.asm`, debug, watch 40H–45H.

**Expected output:** 40H–45H hold a copy of 30H–35H.
