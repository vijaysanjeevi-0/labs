# Ex 4.1 — LED blink (Embedded C)

**Aim:** Blink an LED on P2.0 using Embedded C.

**Tools:** Keil uVision, AT89C51, `REG51.H`.

**Run:** build `led_blink.c`, run in the simulator, watch P2.0 in Peripherals > I/O Ports.

**Expected output:** P2.0 toggles between 0 and 1.

**Note:** the record's aim mentions P0.0, but its own code drives P2.0; the code is kept as the record wrote it.
