# Ex 4.2 — Arithmetic (Embedded C)

**Aim:** Perform arithmetic operations in Embedded C and write results to ports.

**Tools:** Keil uVision, AT89C51, `REG51.H`.

**Run:** build `arithmetic.c`, run in the simulator, watch P0–P3.

**Expected output:** `P0 = 0x0C` (12), `P1 = 0x14` (20), `P2 = 0x40` (64), `P3 = 0x04` (4), for `a=0x10, b=0x04`.
