# Ex 6.1 viva — Communication methods

1. **Zigbee vs Bluetooth vs GSM — which has the longest range?** GSM (cellular, kilometres); Zigbee and Bluetooth are both short-range (tens of metres).
2. **Which of these is built for mesh networking?** Zigbee — nodes can relay for each other, extending coverage.
3. **What does GSM need that the others don't?** A SIM card and a cellular network subscription.
4. **Which is lowest power?** Zigbee, by design, for battery-powered sensor nodes.
5. **Give one real-world use for each.** Zigbee: smart-home sensors/mesh. Bluetooth: wireless headphones/short-range pairing. GSM: remote IoT devices needing wide-area coverage (e.g. asset trackers).
