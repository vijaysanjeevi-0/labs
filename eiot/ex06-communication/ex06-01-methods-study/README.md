# Ex 6.1 — Different communication methods with IoT devices

**Aim:** Study Zigbee, GSM and Bluetooth as IoT communication methods.

**Apparatus / Tools required:** None (study experiment).

Zigbee (IEEE 802.15.4, low-power mesh, short range), GSM (cellular, wide area, SIM-based) and Bluetooth (2.4 GHz, short range, serial over HC-05) are compared by range, power draw and data rate.

**Program:** No program — study only.

**Result:** Zigbee, GSM and Bluetooth were studied and compared as communication methods for IoT devices.
