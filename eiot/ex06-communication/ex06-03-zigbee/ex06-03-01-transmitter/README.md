# Ex 6.3.1 — Zigbee transmitter

**Tools:** Arduino IDE 2.0, Arduino UNO, Zigbee module, jumper wires.

**Connections**

| Arduino UNO pin | Zigbee module |
|---|---|
| 5V | VCC |
| GND | G |
| 2 | Tx |
| 3 | Rx |

**Run:** open `ex06-03-01-transmitter/ex06-03-01-transmitter.ino`, upload.

**Expected output:** the board sends `A` then `B` repeatedly, 100 ms apart.
