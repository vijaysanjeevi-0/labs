# ex03-metadata-extraction viva — Metadata Extraction using FOCA / SearchDiggity

1. **What is metadata, in this context?** Hidden data embedded in a file by the authoring software — author, edit history, file paths, GPS tags.
2. **What is FOCA used for?** Automatically harvesting public documents from a domain and extracting their metadata to map an organisation's internal footprint.
3. **Why do internal file paths in metadata matter to an attacker?** They reveal server names, usernames and folder structure useful for social engineering or targeting specific systems.
4. **What is a Google Dork?** A search query using Google's advanced operators (site:, filetype:) to find specific exposed content.
5. **How would an organisation defend against this?** Strip metadata before publishing documents, or publish as flattened PDFs/images with metadata scrubbed.
