# Ethical Hacking Lab (CCS344)

Every experiment is tool/CLI-driven — no custom source code to write. Each folder's README gives the exact commands in the order that reproduces the manual's output.

| Exp | Folder | Tool(s) |
|---|---|---|
| 1 | ex01-install-kali-metasploitable | VirtualBox, Kali, Metasploitable2 |
| 2 | ex02-reconnaissance | whois, nslookup, host, dig, traceroute, Shodan |
| 3 | ex03-metadata-extraction | FOCA, SearchDiggity, Google Dorks |
| 4 | ex04-maltego | Maltego CE |
| 5 | ex05-robtex | Robtex, curl, nslookup |
| 6 | ex06-nessus-scan | Nessus Essentials |
| 7 | ex07-wireshark-capture | Wireshark, tshark |
| 8 | ex08-armitage-exploit | Armitage, Metasploit Framework |

All exercises target the lab's own Metasploitable2/Kali VMs on a host-only network — never a real external system.

Each folder has its own `README.md` (Aim, Apparatus, Algorithm, Procedure/commands, Sample output, Result) and `VIVA.md`.
