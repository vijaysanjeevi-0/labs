# ex04-maltego viva — Information Gathering using Maltego

1. **What is a transform in Maltego?** A single query unit that fetches related data for an entity from one public data source.
2. **What is OSINT?** Open-Source Intelligence — information gathered from publicly available sources, not hacking or illegal access.
3. **Why visualise entities as a graph instead of a list?** Relationships (which person owns which domain, which IP hosts which service) are far easier to spot visually than in flat text.
4. **What does the 'Company Stalker' machine automate?** A pre-built chain of transforms aimed at mapping a company's domains, emails and documents in one run.
5. **What is an ASN?** Autonomous System Number — identifies which network/ISP owns a block of routed IP addresses.
