# Ex 3 — Applications using sockets

**Aim:** Write Java applications using TCP and UDP sockets: echo, file transfer, chat.

| Folder | Program |
|---|---|
| `ex03-01-echo/` | TCP echo client/server |
| `ex03-02-file-transfer/` | TCP file transfer |
| `ex03-03-udp-chat/` | UDP chat |

Each has its own `README.md` and `VIVA.md`. Compile with `javac *.java` inside the sub-folder and always start the server first.
